# Changelog

All notable changes to the GitHub Cloud integration will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-beta] - 2024-03-19

### Added
- Initial release of GitHub Cloud integration
- Support for syncing repositories, pull requests, issues, teams, and workflows
- Real-time updates via webhooks
- Rate limit handling and pagination support
- Pure async implementation using Ocean's HTTP client
- Comprehensive test coverage
- Documentation and setup instructions
